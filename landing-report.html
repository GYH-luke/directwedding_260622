01 · 개선 배경

기존 페이지의 한계

기존 랜딩페이지는 정보 전달에 치중되어 있어, 즉각적인 DB 확보(신청 전환)에 취약한 구조였습니다.

🎯
전환 목표 불명확
CTA가 "내 맞춤 혜택 확인하기"로 추상적이며, 폼 도달까지 섹션 이동이 많아 전환 경로가 길었습니다.
📋
불필요한 섹션 과다
파트너사 슬라이드, 3단계 스텝폼, 3컬럼 대형 푸터 등 전환에 기여하지 않는 콘텐츠가 페이지를 길게 만들었습니다.
📸
후기 신뢰도 부족
실제 커플 사진 없이 아이콘·해시태그 기반으로 구성되어 진정성 전달이 미흡했습니다.
개선 핵심 방향
① 신청(DB 확보)까지의 경로 단축   ② 실 후기·이미지로 신뢰 강화   ③ 긴급성 장치로 즉시 전환 유도

03 · 카피 변경

헤드라인 · CTA 카피 Before / After

BEFORE · 히어로 메인 헤드라인
"복잡한 결혼준비, 한 번에 끝내는 법"
AFTER
"다이렉트 결혼준비 웨딩박람회"
→ 솔루션 약속형 → 이벤트 명확화. 랜딩 목적(박람회 신청)을 첫 화면에서 직접 제시해 이탈 전 전환 의지를 높임.
BEFORE · 히어로 CTA 버튼
"내 맞춤 혜택 확인하기 →"
AFTER
"박람회 예약하기 →" + 서브: "(박람회 일정 확인하기)"
→ '확인'(소프트) → '예약'(하드 전환)으로 행동 강도 상향. 서브 텍스트로 일정 탐색 니즈도 동시 커버.
BEFORE · 후기 섹션명
"실제 커플들의 이야기"
AFTER
"100% 실제 방문 고객 후기"
→ 검증 가능한 숫자(100%)와 '방문'이라는 구체적 행동을 명시해 신뢰도를 높이고 의심을 선제 차단.

03 · 카피 변경

혜택·긴급성 카피 Before / After

BEFORE · 혜택 섹션 헤드라인
"지금 등록하면 받는 혜택"
AFTER
"날 더울 때 방문하시니까, 1년 중 가장 시원하게 혜택 쏩니다."
→ 시즌성을 활용한 감성 카피. '지금 이 시기에 방문하면 더 유리하다'는 인식을 심어 즉시 행동을 유도.
BEFORE · 신청폼 긴급성 장치
없음
AFTER
🚨 잔여 좌석이 얼마 남지 않았습니다. (깜빡이 효과)
→ 폼 진입 직전 FOMO 자극. 이미 신청 의향이 있는 유저의 이탈을 막는 마지막 허들 제거 장치.
BEFORE · 플로팅 CTA
없음
AFTER
"지금 신청하면 입장료, 플래너비, 상담비 모두 0원" + "바로 예약하기 →"
→ 스크롤 위치 무관하게 핵심 혜택과 CTA를 항상 노출. 중간 이탈 방지 및 재유입 트리거 역할.

04 · 변경 의도

신청 폼 구조 변경 — 가장 중요한 개선

DB 수집 품질과 노쇼율에 직접 영향을 미치는 폼 구조를 전면 재설계했습니다.

BEFORE · 3단계 스텝폼
① 결혼 예정 시기 선택 (4개 보기)
② 이름 · 연락처 입력
③ 완료 → 카카오 상담 유도
✗ 단계마다 이탈 발생
✗ 방문 날짜 미수집 → 노쇼 관리 불가
✗ 카카오 채널로 이동 유도 → 외부 이탈
AFTER · 단일 폼
이름 (한글·영문 유효성 검사)
휴대폰 번호 (자동 하이픈)
결혼 예정일 (월 선택 캘린더)
박람회 방문 희망일 (주말만 선택)
✓ 한 화면 완결 → 이탈 지점 제거
✓ 방문일 수집 → 노쇼 사전 관리 가능
✓ 주말 제한 → 실제 방문 가능 DB만 수집

06 · 기대 효과

전환율(CPA) 개선 관점 종합 정리

↑
폼 전환율 개선
3단계 스텝 → 단일 폼 전환으로 폼 내 이탈 지점 제거. 유효성 검사와 캘린더 피커로 입력 오류 감소.
↑
DB 리드 품질 향상
방문 희망일 수집 + 주말만 선택 제한으로 실제 방문 가능한 고품질 DB만 확보. 노쇼율 감소 기대.
↓
이탈률 감소
플로팅 CTA 상시 노출, 긴급성 카피(🚨), 잔여팀 카운터로 중간 이탈 방지 장치 다층화.
↑
신뢰도 제고
실제 커플 사진 후기, 구어체 텍스트로 진정성 강화. FAQ를 신청폼 뒤에 배치해 신청 후 불안 해소.

SUMMARY

전체 변경 항목 요약

구분 기존 수정본 변경 의도
히어로 카피 "복잡한 결혼준비, 한 번에 끝내는 법" "다이렉트 결혼준비 웨딩박람회" 목적(박람회 신청) 직접 명시
CTA "내 맞춤 혜택 확인하기" "박람회 예약하기 →" 행동 강도 상향 (확인→예약)
파트너 섹션 무한 슬라이드 존재 삭제 불필요 이탈 요소 제거
혜택 UI 5개 탭 (탭 전환 필요) 이미지 카드 세로 나열 모든 혜택 자동 노출
신청폼 3단계 스텝폼 단일 폼 + 방문일 캘린더 이탈 제거 + 리드 품질 향상
FAQ 위치 신청폼 앞 신청폼 뒤 신청 전 이탈 방지
긴급성 없음 🚨 깜빡이 + 잔여팀 카운터 FOMO 유발 즉시 전환 유도
플로팅 CTA 없음 하단 고정 플로팅 바 스크롤 중 전환 경로 상시 확보
키컬러 골드 (#c9913a) 코랄핑크 (#F0556E) 타겟 공감대 + 광고 톤 일치
11
CONCLUSION

모든 변경은
DB 전환(CPA)을
중심에 두고 설계되었습니다.

  • 페이지 목적(박람회 신청)을 첫 화면부터 명확히 제시, 방문자의 의사결정 속도를 높였습니다.
  • 불필요한 섹션 제거 및 폼 단순화로 전환 경로를 최대한 단축했습니다.
  • 실 후기 사진, 긴급성 장치, 플로팅 CTA를 통해 전환 저항 요소를 다층으로 제거했습니다.
  • 방문일 수집 폼으로 DB 품질을 높여 노쇼 관리 및 후속 상담 효율을 개선했습니다.
